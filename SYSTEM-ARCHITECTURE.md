## The Four Stages & Their Rhythms

### Stage 1: Problem Validation

```
PRIMARY GOAL: Prove people want this

Daily focus:
  → Customer conversations (mom-test)
  → Document patterns (customer-tracker)

Weekly check:
  → # conversations: [X] / 50 target
  → % with emotion: [X%] / 60% target

Frameworks in rotation:
  1. mom-test (asking the right questions)
  2. four-steps (finding earlyvangelists)
  3. obviously-awesome (early positioning)

Exit criteria:
  • 50+ conversations
  • 60%+ described pain emotionally
  • 5+ built workarounds (strong signal)
  • Clear earlyvangelist profile

Then move to: Solution Validation
```

### Stage 2: Solution Validation

```
PRIMARY GOAL: Prove people will pay

Daily focus:
  → Building MVP (lean-startup)
  → Pricing conversations (monetizing-innovation)
  → Asking for money (100m-offers)

Weekly check:
  → Paying customers: [X] / 10 target
  → 30-day retention: [X%] / 40% target

Frameworks in rotation:
  1. lean-startup (build-measure-learn)
  2. monetizing-innovation (pricing)
  3. storybrand (messaging)
  4. 100m-offers (offer design)

Exit criteria:
  • 10+ paying customers
  • 40%+ retention after 30 days
  • Clear value prop in customer words
  • Know why people churn

Then move to: Business Model Validation
```

### Stage 3: Business Model Validation

```
PRIMARY GOAL: Prove we can do this profitably

Daily focus:
  → Channel testing (traction)
  → CAC optimization (100m-leads)
  → Unit economics tracking (metrics-dashboard)

Weekly check:
  → CAC: $[X] (must be < LTV/3)
  → LTV: $[X]
  → Channel performance breakdown

Frameworks in rotation:
  1. traction (Bullseye Framework)
  2. 100m-leads (channel execution)
  3. monetizing-innovation (optimize pricing)
  4. lean-startup (measure engines)

Exit criteria:
  • CAC < LTV/3 consistently
  • One repeatable, profitable channel
  • Payback period <12 months
  • Clear why customers come + stay

Then move to: Growth
```

### Stage 4: Growth

```
PRIMARY GOAL: Scale what works

Daily focus:
  → Multi-channel optimization (traction)
  → Crossing to mainstream (crossing-chasm)
  → Category leadership (blue-ocean)

Weekly check:
  → WoW growth: [X%] / 10%+ target
  → Channel mix (2-3 = 80% of growth)

Frameworks in rotation:
  1. crossing-the-chasm (mainstream adoption)
  2. traction (multi-channel)
  3. blue-ocean-strategy (escape competition)
  4. All frameworks as needed

Success state:
  • 10%+ WoW growth sustained
  • 2-3 validated channels
  • Strong market position
  • Sustainable unit economics

Then: You've graduated this playbook
```

## The Meta-Architecture

This entire system is built on three principles:

### 1. Progressive Disclosure
```
High-level  → founder-os (daily workflow)
  ↓
Mid-level   → diagnose (problem → framework routing)
  ↓
Deep-level  → individual skills (detailed methods)

You only go deeper when you need to.
```

### 2. Systematic Application
```
Not: Read 14 frameworks → Try to remember them → Maybe apply one
But: Daily system → Routes to framework → Forces application → Measures result
```

### 3. Honest Feedback Loops
```
Daily:   Did SMIT move the metric?
Weekly:  Is constraint actually moving?
Monthly: Should we pivot/stay/advance?

System catches problems in weeks, not months.
```

## Final Architecture Principle

**The system is designed to become invisible.**

### Month 1
You're very conscious of the system:
- "I need to do my daily standup"
- "Which framework should I use?"
- "Let me check the weekly review template"

### Month 3
The system starts fading:
- Daily standup takes 5 minutes (you know the questions)
- Framework selection is intuitive
- Reviews reveal patterns quickly

### Month 6
The system is invisible:
- You just "do a standup" (second nature)
- You automatically apply the right framework
- You catch anti-patterns before they hurt
- **It's just how you work**

That's when you know you've mastered the system.

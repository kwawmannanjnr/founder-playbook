# Founder Operating System

> "The best founders don't just know the frameworks - they have systems that force them to use the frameworks at the right time."

## What This Is

This is not another framework to learn. This is a **practical operating system** that integrates the 14 business frameworks into your actual work.

It includes:
- **Daily Priority Protocol** - What to focus on today (10 minutes/day)
- **Weekly Review System** - Honest assessment of progress (45 minutes/week)
- **Decision Maker** - When facing a hard choice (5-20 minutes)
- **Metrics Dashboard** - What to actually measure (ongoing)
- **Anti-Pattern Detector** - Catch yourself making classic mistakes (ongoing)
- **Monthly Strategic Review** - Are you still on the right path? (2 hours/month)

## Daily Priority Protocol (10 minutes every morning)

Start every day by answering three questions:

### 1. What's the current stage?

```
What are you trying to prove right now?
|-- "Does anyone actually want this?"
|   → STAGE: Problem Validation
|   → Priority: Customer conversations (mom-test)
|   → Target: 10 quality conversations this week
|
|-- "Will people pay for it?"
|   → STAGE: Solution Validation  
|   → Priority: Get money or binding commitments
|   → Target: 5 paying customers or signed LOIs
|
|-- "Can we build it profitably?"
|   → STAGE: Business Model Validation
|   → Priority: Unit economics + repeatable process
|   → Target: CAC < LTV/3, proven channel
|
|-- "Can we scale it?"
|   → STAGE: Growth
|   → Priority: Systematic channel expansion
|   → Target: 3+ scalable channels validated
```

### 2. What's the one bottleneck?

**The One Thing Rule:** Every day, identify the single biggest constraint preventing you from moving to the next stage.

```
Current constraint is...
|-- Customer access → Use traction Phase I channels (today)
|-- Understanding what they want → Use mom-test (today)
|-- Messaging clarity → Use storybrand BrandScript (today)
|-- Product quality → Use lean-startup iteration (today)
|-- Pricing model → Use monetizing-innovation WTP (today)
|-- Sales process → Use spin-selling SPIN sequence (today)
|-- Category confusion → Use obviously-awesome 5+1 (this week)
|-- Positioning → Use obviously-awesome (this week)
|-- Growth channel → Use traction Bullseye (this week)
```

### 3. What's the Single Most Important Task (SMIT)?

Write one task that directly addresses the bottleneck. Make it:
- **Specific**: Not "work on marketing" but "write 10 DMs using ACA framework"
- **Completable today**: Not a project, a task
- **Directly moves the constraint**: Not busy work

**Template:**
```
Today's SMIT: [One task that directly addresses the bottleneck]
Done when: [Concrete completion criteria]
Skills needed: [Which framework/skill applies]
```

**Examples:**
- ❌ "Work on positioning" - too vague
- ✅ "Complete Obviously Awesome worksheet sections 1-3 for developer persona"

- ❌ "Get customers" - not completable
- ✅ "Send 15 outreach DMs to iOS devs who posted about onboarding problems this week"

- ❌ "Fix the website" - no completion criteria  
- ✅ "Rewrite homepage hero using StoryBrand BrandScript - test with 5-second test"

## Weekly Review System (45 minutes, Friday afternoon)

### Part 1: Evidence-Based Progress (15 minutes)

Fill in this week's numbers honestly:

```markdown
## Week of [DATE]

### Leading Indicators (the actions you took)
- Customer conversations: [X] (target: 10+)
- Outreach attempts: [X] (depends on channel)
- Product iterations shipped: [X] (target: 1-2)
- Channel tests run: [X] (target: 1 new, 1 optimization)

### Lagging Indicators (the results that happened)
- Signups/leads: [X] (week-over-week: +/- X%)
- Paying customers: [X] (week-over-week: +/- X)
- Revenue: $[X] (week-over-week: +/- X%)
- Retention: [X%] (compare to last week)

### Qualitative Evidence
- Best customer insight this week: [write it]
- Biggest surprise: [write it]
- Pattern I'm starting to see: [write it]
```

### Part 2: Framework Checkup (15 minutes)

Run through this checklist every week to catch common traps:

```
□ Mom Test check: Did I ask about past behavior, not future intentions?
□ Lean Startup check: Did I validate assumptions or just build?
□ Four Steps check: Am I still in discovery/validation, or did I jump to scaling?
□ Traction check: Did I test distribution as rigorously as product?
□ Monetizing Innovation check: Did I talk about price or just features?
□ StoryBrand check: Is my messaging about the customer or about me?
□ Obviously Awesome check: Can a stranger tell what category I'm in?
□ Influence check: Am I giving before asking?
```

### Part 3: Next Week Planning (15 minutes)

Based on the evidence:

```
Stage: [Validation/Growth/Scale]
Biggest constraint: [One thing]
Hypothesis to test: [What you think is true but haven't proven]
Next week's SMIT theme: [Customer access / Messaging / Product / Pricing / Sales]

Three Most Important Tasks:
1. [Task] - [Framework to use] - [Done when]
2. [Task] - [Framework to use] - [Done when]
3. [Task] - [Framework to use] - [Done when]
```

## Decision Maker (Use when stuck on a hard choice)

### Step 1: Frame the Decision

```
Decision: [State it as a clear yes/no or A vs B]
Context: [One paragraph - what's the situation]
Why this matters: [What happens if we get this wrong]
```

### Step 2: Apply the Right Framework

```
Decision Type: [Pick the closest]
|-- "Should we pivot?" → Use lean-startup pivot catalog
|-- "Which customer segment?" → Use four-steps earlyvangelist hierarchy
|-- "What should we charge?" → Use monetizing-innovation WTP + good/better/best
|-- "Which marketing channel?" → Use traction Bullseye Framework
|-- "How should we position?" → Use obviously-awesome 5+1 components
|-- "Is this the right market?" → Use crossing-the-chasm market type
|-- "Should we compete here?" → Use blue-ocean-strategy ERRC grid
|-- "How do I make this message land?" → Use made-to-stick SUCCESs
|-- "What should the offer include?" → Use 100m-offers value equation
|-- "How do I close this deal?" → Use spin-selling SPIN sequence
|-- "What distribution strategy?" → Use 100m-leads core-four
|-- "How do I say no to a request?" → Use influence reciprocity + consistency
|-- Other → Use diagnose skill first
```

### Step 3: Run the Framework

Open the relevant skill file and work through its decision tree or scorecard.

### Step 4: Make the Call

```
Decision: [Yes/No or Option A/B]
Framework used: [Name]
Key insight that decided it: [One sentence]
Reversible? [Yes/No] - if yes, time-box the experiment
Commit: [What concrete action starts tomorrow]
```

**The Irreversibility Rule:** If the decision is reversible, spend 15 minutes on it max. If it's irreversible (hiring, legal, killing the company), spend 2 hours minimum and talk to 2-3 people who've made similar decisions.

## Metrics Dashboard (Track These, Ignore Everything Else)

### Problem Validation Stage

```
Primary Metric: # of problem-validation conversations (target: 50)
Secondary: % who described the problem with emotion and specifics (target: >60%)
Anti-metric: Don't track "interest" or "likes the idea" - useless
```

### Solution Validation Stage

```
Primary Metric: # of paying customers (target: 10)
Secondary: Retention after 30 days (target: >40%)
Anti-metric: Don't track signups or trial users - vanity
```

### Business Model Validation Stage

```
Primary Metric: CAC vs LTV ratio (target: CAC < LTV/3)
Secondary: Time to first value (target: <7 days)
Anti-metric: Don't track revenue alone without CAC - misleading
```

### Growth Stage

```
Primary Metric: Week-over-week growth rate (target: >10% sustained)
Secondary: Channel contribution breakdown (target: 2-3 channels = 80% of growth)
Anti-metric: Don't track gross revenue without cohort analysis - hides churn
```

**The Dashboard Rule:** Track 2 metrics per stage. Not 10. If you have 10 metrics, you're measuring motion instead of progress.

## Anti-Pattern Detector (Run This When Something Feels Off)

### Pattern: "Lots of Interest, No Money"

```
Symptoms:
- People say they'd "definitely use this"
- Getting warm introductions and great conversations  
- Zero paying customers or binding commitments

What's Actually Happening:
→ You're asking about the future, not the past (mom-test violation)
→ You're talking to people who are interested, not people in pain (four-steps earlyvangelist violation)

Fix:
1. Re-run conversations: "Walk me through the last time this problem cost you time/money"
2. Apply earlyvangelist hierarchy: Have they built a workaround?
3. Ask for money or binding commitment TODAY

Framework: mom-test + four-steps
Time to fix: 1-2 weeks
```

### Pattern: "We Just Need More Features"

```
Symptoms:
- Low conversion or high churn
- Customers say they'll come back when X feature exists
- Your roadmap is 30+ features deep

What's Actually Happening:
→ You have a positioning problem, not a feature problem (obviously-awesome)
→ Or a messaging problem (storybrand)
→ Or your product doesn't create enough value yet (lean-startup hypothesis failure)

Fix:
1. Ask churned users: "What were you hoping this would do?"
2. Check if feature requests are real needs or polite rejections
3. Run obviously-awesome positioning if customers can't articulate what you do
4. Run storybrand 5-second test if positioning is clear but messaging isn't landing

Framework: obviously-awesome or storybrand
Time to fix: 1-2 weeks
```

### Pattern: "We Need to Raise Money to Grow"

```
Symptoms:
- Growth has stalled
- Thinking fundraising will unlock growth
- Haven't identified why current channel stopped working

What's Actually Happening:
→ You've exhausted one channel without finding the next (traction)
→ Or your unit economics don't work (monetizing-innovation)
→ Money won't fix a broken growth engine

Fix:
1. Calculate CAC and LTV honestly
2. If CAC > LTV/3, fix pricing or cost structure BEFORE raising
3. Run traction Bullseye to find next channel
4. Only raise when you have a repeatable, profitable channel and need fuel

Framework: traction + monetizing-innovation
Time to fix: 4-8 weeks
```

### Pattern: "Everyone Is Our Customer"

```
Symptoms:
- Can't describe your ideal customer in one sentence
- Saying "small businesses" or "consumers" or "enterprises"
- Marketing messaging is generic

What's Actually Happening:
→ You haven't done customer slicing (four-steps)
→ Or you're afraid to narrow (crossing-the-chasm)
→ Trying to be everything to everyone = invisible to everyone

Fix:
1. List every customer type you've talked to
2. Score each on four-steps earlyvangelist hierarchy
3. Pick the ONE segment that scores highest
4. Rewrite all messaging for that segment only
5. Watch what happens

Framework: four-steps + obviously-awesome
Time to fix: 1 week
```

### Pattern: "We're Growing But Not Making Money"

```
Symptoms:
- User growth looks good
- Revenue growing but slower than users
- Burning cash, assuming scale will fix it

What's Actually Happening:
→ Wrong monetization model (monetizing-innovation)
→ Or wrong pricing (too low or too complicated)
→ Or growing the wrong users (they don't convert)

Fix:
1. Run cohort analysis: which users actually pay?
2. Calculate conversion rate by acquisition channel
3. Run monetizing-innovation WTP conversations with paying users
4. Consider switching monetization model (subscription → usage, freemium → free trial)
5. Stop optimizing for vanity metrics

Framework: monetizing-innovation + lean-startup engines
Time to fix: 2-4 weeks
```

## Monthly Strategic Review (2 hours, first Friday of the month)

### Part 1: Brutal Honesty (30 minutes)

```
## [MONTH] Review

### What We Said We'd Accomplish
[Write what you planned last month]

### What Actually Happened
[Write what actually happened - numbers and evidence]

### The Gap
Bigger than planned: [What exceeded expectations]
Missed entirely: [What didn't happen and why]
Learned: [What assumption was wrong]

### Founder Honesty Check
□ Am I working on the constraint or avoiding it?
□ Am I measuring reality or vanity?
□ Am I talking to customers or just building?
□ Am I making decisions or deferring them?
□ Am I learning or defending my original idea?
```

### Part 2: Stage Assessment (30 minutes)

```
Current Stage: [Problem / Solution / Business Model / Growth]

Evidence we should move to next stage:
- [Metric or proof point]
- [Metric or proof point]
- [Metric or proof point]

Evidence we're not ready:
- [What's still unproven]
- [What's still unproven]

Honest call: [Stay in current stage / Move to next / Pivot]

If staying: What assumption are we testing this month?
If moving: What's the new constraint?
If pivoting: Which type? (Use lean-startup pivot catalog)
```

### Part 3: Framework Health Check (30 minutes)

Go through each framework and score yourself honestly (0-10):

```
[ /10] mom-test - Am I actually validating or just pitching?
[ /10] four-steps - Do I know who my earlyvangelists are?
[ /10] lean-startup - Am I measuring learning or just motion?
[ /10] obviously-awesome - Can a stranger tell what I do?
[ /10] crossing-the-chasm - Do I have a beachhead strategy?
[ /10] blue-ocean-strategy - Am I competing on value or price?
[ /10] monetizing-innovation - Did I design product+price together?
[ /10] spin-selling - Can I articulate customer pain in their words?
[ /10] 100m-offers - Is my offer genuinely hard to say no to?
[ /10] 100m-leads - Do I have a repeatable lead gen system?
[ /10] influence - Am I giving value before asking?
[ /10] traction - Have I tested multiple channels systematically?
[ /10] storybrand - Is my messaging about the customer or me?
[ /10] made-to-stick - Will people remember my pitch in 48 hours?

Lowest 3 scores: [List them]
Action: Pick ONE to improve this month
```

### Part 4: Next Month Plan (30 minutes)

```
## [NEXT MONTH] Plan

Primary Goal: [One sentence - what are we proving/achieving]
Success Criteria: [Specific number or milestone]

Top 3 Priorities:
1. [Priority] - [Why] - [Framework to use]
2. [Priority] - [Why] - [Framework to use]  
3. [Priority] - [Why] - [Framework to use]

What I'm explicitly NOT doing:
- [Thing that seems urgent but isn't the constraint]
- [Thing that seems urgent but isn't the constraint]

Biggest Risk: [What could derail this plan]
Mitigation: [What I'm doing about it]
```

## How to Use This System

### Week 1: Setup

1. Read the diagnose skill first if you haven't
2. Determine your current stage (Problem/Solution/Business Model/Growth)
3. Run your first weekly review using this template
4. Set up your metrics dashboard (2 metrics only)

### Weeks 2-4: Build the Habit

1. Daily Priority Protocol every morning (10 minutes)
2. When stuck on a decision, use the Decision Maker
3. Friday weekly review (45 minutes)
4. Run Anti-Pattern Detector when something feels off

### Month 2+: Optimization

1. Monthly Strategic Review (first Friday)
2. Refine which frameworks you need most
3. Stop using frameworks that don't apply to your stage

1. Daily Protocol → tells you what to focus on today
2. Diagnose Skill → routes you to the right framework
3. Framework Skills → gives you the detailed method
4. Back to Daily Protocol → apply what you learned

## The Meta-Rule

**Frameworks are tools, not rules.**

- If a framework tells you to do X but your gut says Y, investigate why.
- If you've scored 10/10 on a framework's checklist but nothing improved, the framework doesn't fit your situation.
- If following the system makes you less effective, the system is wrong - not you.

The Operating System exists to help you think more clearly. It doesn't think for you.

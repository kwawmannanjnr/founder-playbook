## Quick Filters (30 seconds)

Before starting work, check these:

**Is today's SMIT...**
- [ ] Directly moving the primary constraint?
- [ ] Measurable (will I know if it's done)?
- [ ] Completable in one day?

**If any NO:** Rewrite the SMIT before starting work.

**Am I avoiding the uncomfortable thing?**
- [ ] Yes (Be honest. What's the uncomfortable task you should do instead?)
- [ ] No

**If yes:** Consider doing that uncomfortable thing as today's SMIT.

## Examples: Good vs Bad SMITs

### ❌ Bad SMITs (Too Vague)

- "Work on marketing"
- "Improve the product"  
- "Talk to customers"
- "Research competitors"
- "Fix bugs"

**Why bad:** No completion criteria, too broad, not directly moving a constraint.

---

### ✅ Good SMITs (Specific & Completable)

**Problem Validation Stage:**
- "Conduct 5 mom-test conversations with iOS developers who posted about onboarding problems this week"
- "Score 10 previous customer conversations using four-steps earlyvangelist hierarchy"

**Solution Validation Stage:**
- "Rewrite homepage using storybrand BrandScript, run 5-second test with 5 strangers"
- "Send pricing proposal to 3 warmest leads using monetizing-innovation good/better/best structure"

**Business Model Validation Stage:**
- "Calculate CAC and LTV for last 30 days using actual data, identify which channel has best ratio"
- "Test 'Speaking Engagements' channel (Traction Phase I): secure 1 speaking slot at local meetup"

**Growth Stage:**
- "Launch Bullseye Framework test #2 (Targeting Blogs): pitch 10 relevant blogs with data-driven story angle"
- "Analyze retention cohorts from last 3 months, identify drop-off point in Days 1-7"

## The Honesty Rule

This standup only works if you're honest with yourself.

**Signs you're lying:**
- Marking SMITs complete when they're 80% done
- Setting easy SMITs to guarantee completion
- Blaming external factors for missed SMITs 3+ days in row
- Not actually doing the uncomfortable task you identified
- Writing "work on X" because you don't want to commit to specifics

**If you catch yourself doing ANY of these:** Stop. Reread the Founder OS SKILL.md section on brutal honesty. The system is designed to help you, but only if you use it honestly.

## Integration with Weekly Review

These daily standups feed into your Friday Weekly Review:

- **SMITs completed** → Becomes "Leading Indicators"
- **Constraint tracking** → Shows if constraint is moving  
- **Patterns in blocking factors** → Reveals systemic issues
- **Time allocation** → Shows if you're working on what matters

If you do daily standups all week, the weekly review takes 30 minutes instead of 45.

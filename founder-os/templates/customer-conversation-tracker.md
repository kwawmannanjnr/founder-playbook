### Earlyvangelist Score (Four Steps Framework)

Rate this person 1-10 on each:

```
[ /10] Has the problem (experiences it frequently)
[ /10] Knows they have the problem (actively looking for solution)
[ /10] Has been actively looking for solution (not just tolerating pain)
[ /10] Has assembled solution from pieces (spreadsheet, manual process, etc)
[ /10] Has budget / can pay (or authority to allocate)

Total: [ /50]

30+: Strong earlyvangelist candidate - prioritize
20-29: Lukewarm - keep talking but don't over-invest
<20: Polite interest only - learn from them but don't build for them
```

## Mom Test Violations to Avoid

After each conversation, check yourself:

**Did I...**
- [ ] Talk about my idea too much? (Should be 10% you talking, 90% them)
- [ ] Ask "Would you use this?" (Useless question - ask about past behavior)
- [ ] Accept vague hypotheticals? ("I'd probably..." = meaningless)
- [ ] Let them be nice instead of honest? (Push for specifics)
- [ ] Ask leading questions? (Phrase questions to get truth, not validation)

**If you checked ANY boxes:** The conversation was less useful than it could have been. Adjust approach for next one.

## Quick Reference: Good vs Bad Questions

### ❌ Bad Questions (Avoid These)

- "Would you use this?"
- "Do you think this is a good idea?"
- "How much would you pay for this?"
- "What features would you want?"
- "Would this solve your problem?"

These all ask about the future or invite politeness. Useless.

### ✅ Good Questions (Use These)

- "Tell me about the last time [problem] happened."
- "What are you doing about it now?"
- "What have you tried that didn't work?"
- "How much does [current solution] cost you?"
- "Walk me through your process for [relevant task]."
- "Who else would need to approve this?"

These ask about past behavior and current reality. Useful.

## When to Stop Conversations and Start Building

You're ready when:

- [ ] 10+ conversations completed
- [ ] 5+ people scored >30 on earlyvangelist scale
- [ ] 3+ people described the pain with emotion and specifics
- [ ] 3+ people have built workarounds (spreadsheets, manual processes)
- [ ] You can describe the customer segment in one sentence
- [ ] You can articulate their pain in their words, not yours
- [ ] You know what they're paying now for alternatives

If you checked <5 boxes: Keep talking to people.  
If you checked 5-6 boxes: You're close - 5 more conversations.  
If you checked all 7: Stop talking, start building the MVP.

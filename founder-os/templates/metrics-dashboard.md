## Stage-Specific Metrics

### If Problem Validation Stage

#### Primary Metric
**Customer discovery conversations completed**
```
Current: [X] / Target: 50

This week: [X]
This month: [X]
```

#### Secondary Metric
**% describing problem with emotion + specifics**
```
Current: [X]% / Target: >60%

Count:
- With emotion: [X] people
- Vague/polite: [X] people

If <60%: You may have the wrong segment or wrong problem
```

#### Anti-Metrics (DO NOT TRACK)
- ❌ Number who "like the idea"
- ❌ Number who "would use it"
- ❌ Positive feedback
- ❌ Social media engagement on posts about the idea

Why: These measure politeness, not pain. Worthless for validation.

#### Stage Complete When:
- [ ] 50+ conversations done
- [ ] 60%+ described problem with emotion/specifics  
- [ ] You can articulate the problem in customer's words
- [ ] 5+ people have built workarounds (spreadsheets, manual processes)

**Then move to:** Solution Validation


#### Anti-Metrics (DO NOT TRACK)
- ❌ Total signups (without conversion rate)
- ❌ Trial users (without retention rate)

Why: Vanity metrics that hide whether you have real product-market fit.

#### Stage Complete When:
- [ ] 10+ paying customers

- [ ] Customers can articulate value in their words
- [ ] You know exactly why people churn

**Then move to:** Business Model Validation

### If Business Model Validation Stage

#### Primary Metric
**CAC vs LTV ratio**
```
CAC (Customer Acquisition Cost): $[X]
LTV (Lifetime Value): $[X]
Ratio: [X:1] / Target: 3:1 or better

Calculation:
- Total sales/marketing spend: $[X]
- New customers acquired: [X]
- CAC = spend / customers = $[X]

- Avg revenue per customer: $[X]/mo
- Avg customer lifetime: [X] months
- LTV = revenue × lifetime = $[X]

LTV/CAC = [X]

If <3:1: Economics don't work yet - fix pricing or reduce CAC
If 3-5:1: Healthy - ready to scale
If >5:1: You're under-spending on growth
```

#### Secondary Metric
**Time to first value**
```
Current: [X] days / Target: <7 days

Cohort data:
- Signup to activation: [X] days (median)
- Activation to first paid conversion: [X] days (median)

If >7 days: Onboarding friction is killing conversions
```

#### Supporting Metrics
```
Monthly churn rate: [X]% (target: <5%)
Gross margin: [X]% (target: >70% for SaaS)
Payback period: [X] months (target: <12 months)
```

#### Anti-Metrics (DO NOT TRACK)
- ❌ Revenue without CAC context
- ❌ Growth rate without unit economics
- ❌ Signups without conversion context

Why: Growth without profitability = burning money faster.

#### Stage Complete When:
- [ ] CAC < LTV/3 consistently for 2+ months
- [ ] Payback period <12 months
- [ ] Identified one repeatable, profitable channel
- [ ] You know exactly where customers come from

**Then move to:** Growth

## The Two-Metric Rule

**At any stage, track exactly 2 metrics:**
1. Primary (the constraint you're working on)
2. Secondary (the health check to make sure you're not breaking something)

**That's it.**

If you're tracking 10 metrics, you're measuring motion instead of progress.

## Metric Health Checks

Run these checks monthly:

### Are you measuring the right thing?

```
□ Does this metric directly relate to moving to next stage?
□ Can I take action to change this metric?
□ Does this metric measure real customer behavior (not vanity)?
□ Am I tracking this with real data (not gut feel)?

If any NO: Change your metrics
```

### Are you measuring too many things?

```
How many metrics am I actively tracking? [X]

If >2 per stage: You're diffusing focus. Pick the 2 that matter most.
```

### Are you lying to yourself?

```
□ Am I cherry-picking time ranges to show growth?
□ Am I ignoring cohort effects to make numbers look better?
□ Am I measuring "interest" instead of "money"?
□ Am I reporting growth rate without absolute numbers context?

If any YES: You're fooling yourself. Fix it.
```

## The Honest Rule

> "You can lie to investors, you can lie to customers, but you cannot lie to your metrics dashboard."

If the numbers aren't going up and to the right:
1. First assume you're measuring the wrong thing
2. Then assume you're in the wrong stage
3. Then assume you have the wrong product/market/message
4. Last, assume you're executing poorly

Most founders blame #4 when it's actually #1-3.
